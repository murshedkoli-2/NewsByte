# 📰 NewsByte — Real-Time Curated News Discovery & Scraping Engine

[![Node.js](https://img.shields.io/badge/Node.js-20.x-339933?style=for-the-badge&logo=node.js)](https://nodejs.org/)
[![Cheerio](https://img.shields.io/badge/Scraper-Cheerio-E88C1F?style=for-the-badge)](https://cheerio.js.org/)
[![Readability](https://img.shields.io/badge/Parser-Mozilla_Readability-FF4F00?style=for-the-badge)](https://github.com/mozilla/readability)
[![Firebase](https://img.shields.io/badge/Storage-Firebase-FFCA28?style=for-the-badge&logo=firebase)](https://firebase.google.com/)

An automated news aggregation, web scraping, and real-time content delivery platform. Ingests articles from leading international and regional publications, cleans content through Mozilla Readability, and distributes curated feeds.

---

## 🌟 Key Features

- **🕷️ High-Performance Scraping**: Automated feed extraction using Cheerio, Fast-XML-Parser (RSS/Atom), and Mozilla Readability.
- **🔥 Real-time Database**: Synchronization with Firebase for live news updates.
- **🏷️ Smart Categorization**: Automatic tagging by topic (Politics, Tech, Business, Sports, Entertainment).
- **🛡️ Clean Extraction**: Strips paywalls, ads, and clutter to extract pure article text and primary imagery.

---

## 🚀 Getting Started

```bash
git clone https://github.com/murshedkoli-2/NewsByte.git
cd NewsByte
npm install
npm run dev
```
